 ReWear ♻️

A school marketplace prototype for giving pre-loved items a second life.

ReWear is a web-based marketplace prototype developed as part of an MYP5 Digital Design project. It aims to encourage reuse and reduce waste within the school community by providing a platform where students can list, discover, and exchange or give away items they no longer need.

 About the Project

Students often have unused school supplies, textbooks, uniforms and other items that could still be useful to someone else. ReWear explores how a digital platform could make it easier to give these items a second life while encouraging more sustainable consumption.

The project focuses on creating a simple, accessible and user-friendly marketplace experience.

 Features

- Browse Listings: Explore available items and filter listings by condition.
- Create Listings: Add items with a title, category, condition, description and transaction type.
- Image Uploads: Upload listing photos using Cloudinary.
- Item Details: View information about individual listings.
- Google Authentication: Sign in using Google authentication through Firebase.
- Liked Items: Save listings for later.
- My Listings: View listings associated with your account.
- Firestore Database: Store and retrieve listing information dynamically.

 Project Structure

The project is organised into individual HTML pages, shared styling and JavaScript files, Firebase configuration and security rules, and local image assets.

Main pages include:

- `index.html` – Home
- `browse.html` – Browse listings
- `add-listing.html` – Create a listing
- `item-details.html` – View listing details
- `liked-items.html` – Saved listings
- `profile.html` – User profile and personal listings
- `sign-in.html` – Authentication

 Running the Project Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Configure your own Firebase project and update the Firebase configuration.
4. Configure your own Cloudinary cloud name and unsigned upload preset.
5. Open `index.html` using a local development server, such as the VS Code Live Server extension.

Firebase Authentication, Firestore and Cloudinary must be configured for their respective features to work.

 Project Status

This project is a prototype developed for educational purposes as part of an MYP5 Digital Design project.

ReWear demonstrates the concept and functionality of a school-based reuse marketplace. It is not a fully launched or production-ready commercial marketplace.

Features, security measures and workflows may require further development before real-world deployment. Users should not treat the prototype as a verified or fully moderated marketplace.
